# Admin tools

Internal-only, four tabs.

## Post a job

Unlike the recruiter-facing job form, admin job posting **does** have a real AI-writing feature: paste a raw job description blob into the "Extract & Auto-Fill Fields" box and it parses out structured fields (title, skills, requirements, etc.) automatically. Admin-posted jobs also require an **External Apply Link** — these are the jobs that show up with source badges (LinkedIn/Indeed/External) instead of an in-app apply button on the candidate side.

## Campus Codes

A read-only table of every college set up for [Campus Connect](/features/campus-connect) and its 6-digit access code.

## Blocked Candidates

Unblock accounts that got locked out — almost always from a Campus Connect proctoring violation (two tab-switches/full-screen exits during the test). This is the manual undo for that automatic block.

## Test Results

The full Campus Connect leaderboard, sorted by score and filterable by college. Score tiers: **ELITE PERFORMER** (≥80%), **QUALIFIED** (≥60%), **LOW SCORE** (<40%). A CSV export button downloads results grouped by college — this is also the only place anyone (student or otherwise) can actually see a Campus Connect score, since students themselves never see their result in-app.
